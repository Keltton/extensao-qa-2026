# 🧪 Extensão QA – SIFIT

Repositório da atividade de extensão de **Qualidade de Software**: documentação de **testes manuais** do sistema **SIFIT – Sistema para Academias**, no modelo do repositório de referência [extensao-qa](https://github.com/Adnyslougansilva/extensao-qa).

## 🎯 Objetivo
- Aplicar o processo de teste: análise de requisitos → plano → casos de teste → execução → registro de bugs → relatório.
- Documentar evidências de cada execução (vídeos no Jam.dev e prints).

## 🧱 Estrutura
```
SIFIT/
├── 1-Analise de requisitos.md
├── 2-plano de testes.md
├── Cenarios de testes/      ← um arquivo por requisito (CT_RFxx)
├── 3-Relatorio-de-Bugs.md
├── 4- Relatorio dos testes.md
└── Evidencias/              ← prints dos casos sem vídeo
```

## 🧪 Metodologia
- **Técnicas:** caminho feliz, testes negativos, particionamento de equivalência, análise de valor limite, teste exploratório
- **Formato:** BDD (Gherkin) em tabelas Markdown
- **Ferramentas:** navegador Chrome, DevTools (F12), Jam.dev (vídeos), MySQL Workbench (consulta ao banco), GitHub
